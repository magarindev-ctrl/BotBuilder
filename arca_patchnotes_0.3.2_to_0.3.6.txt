    <p style="margin:0 0 10px;">기존 적용 코드에도 항목 병합 기능은 있었지만, 지시와 검토 화면 때문에 전체 로어북을 다시 출력하는 것으로 보일 수 있었습니다. 이번에는 <strong>LLM 출력 지시·예시, 입력 구성, 변경 검토 화면</strong>까지 부분 수정 방식으로 정리했습니다.</p>
    <ul style="margin:0 0 14px;padding-left:22px;">
      <li><code>upsert</code>에는 새 항목 또는 실제 변경한 항목만 넣도록 안내합니다.</li>
      <li>기존 항목은 원래 <code>ref</code>를 사용하고, <code>entry</code>에는 바뀐 필드만 반환합니다. 새 항목은 <code>ref: null</code>과 필수 <code>key</code>·<code>content</code>를 사용합니다.</li>
      <li>생략한 기존 항목·필드는 보존합니다. 삭제는 <code>remove</code>에 지정된 항목만 처리합니다.</li>
      <li>본문을 바꾸면 해당 항목의 완성된 새 본문을 받습니다. 본문 내부의 줄 단위 패치 형식은 아닙니다.</li>
      <li>검증된 응답에서 기존 값과 같은 필드를 제거하고, 변경 검토에는 실제 바뀐 항목·필드만 표시합니다.</li>
      <li>로어북 작업의 현재안·참고자료와 설계 대화의 원고 컨텍스트에 중복 삽입되던 자료를 줄였습니다.</li>
    </ul>
