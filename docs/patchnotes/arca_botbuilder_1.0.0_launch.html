FROM A SINGLE IDEA

이런 요청부터 시작해 보세요.

“기억을 거래하는 항구 도시에서, 자신의 과거만 잊은 안내인을 만들고 싶어.”

“선택한 로어북을 참고해 성격의 모순을 찾아줘. 설명은 필요한 문장만 고쳐줘.”

“세 가지 시작 상황을 만들고, 선택 버튼과 초기 변수도 함께 제안해줘.”

요청 예시입니다. 생성 결과는 사용하는 모델에 따라 달라지며 검토 후 적용합니다.

01   IDEA → CHARACTER

막연한 아이디어를, 함께 다듬는 설정으로.

“기억을 거래하는 도시의 안내인을 만들고 싶어.” 한 문장에서 시작해 LLM과 대화하며 캐릭터와 텍스트 게임의 방향을 잡아보세요.

  • 설계 대화와 제작 노트에 구상과 요구사항을 모으고, 현재 원고를 참고해 다음 작업을 의논합니다.
  • 설명·성격·시나리오·첫 메시지·대체 인사말을 한 작업 공간에서 다룹니다. 필요한 항목은 직접 편집하거나 LLM에 제작·수정을 요청할 수 있습니다.
  • 시작 상황 선택은 첫 메시지, 선택지, Lua, 초기 변수와 필요한 정규식을 묶어 제안받습니다. 분기형 도입부를 구성할 때 연결해야 할 요소를 함께 살펴볼 수 있습니다.

02   CONTEXT YOU CHOOSE

로어북이 많아져도, 이번에 쓸 자료는 직접 선택.

세계관이 길어질수록 중요한 것은 이번 작업에 필요한 설정을 골라 전달하는 일입니다.

  • 로어북마다 이번 요청에 포함을 체크하고, 전체 포함·제외로 빠르게 범위를 정합니다.
  • 로어북·정규식 요청은 현재 선택한 항목만 수정하도록 범위를 좁힐 수 있습니다.
  • 추가하거나 바꿀 항목·필드만 수정안으로 받아 반영합니다. 생략한 기존 항목과 설정은 보존합니다.
  • 많은 로어북도 제목과 선택 체크박스를 구분해 볼 수 있는 목록으로 관리하고, 선택 상태를 작업 저장본에 함께 보관합니다.

03   SMALL EDITS, LONG STORIES

긴 원고도, 긴 코드도. 바꿀 부분에 집중하세요.

설명 한 문장, 로어북 한 단락, CSS의 색상 값, Lua의 변수 처리처럼 필요한 구간만 수정할 수 있습니다.

  • 설명·첫 메시지·로어북·정규식·HTML/CSS 원문·Lua·초기 변수에 텍스트 구간 부분편집을 지원합니다.
  • 변경 전후와 수정 구간을 확인하고 적용합니다. 모델이 부분편집 형식으로 답하면 긴 본문을 매번 다시 출력하는 부담을 줄일 수 있습니다.
  • 일반 문장의 수정 위치가 애매하면 후보 구간 선택·직접 범위 지정·교체 문구 편집·건너뛰기로 의도를 분명히 정합니다.
  • 코드와 변수 값은 원문과 정확히 맞는 구간을 기준으로 처리합니다. 여러 Lua 스크립트도 각각 편집할 수 있습니다.

04   TRY THE TEXT

정규식은 입력부터 치환 결과까지 바로 확인.

패턴을 적고 테스트 문장을 넣어, 무엇을 찾고 어떻게 바꾸는지 텍스트로 살펴보세요.

  • 매칭 결과·캡처 그룹·치환 결과를 같은 편집 흐름에서 확인합니다.
  • 정규식의 이름·패턴·치환문·유형·플래그를 편집하고, HTML/CSS가 들어 있는 출력 원문도 다룹니다.
  • 정규식 테스트는 텍스트 결과 확인에 집중합니다. HTML/CSS 화면 렌더링과 Lua 실행 검증은 실제 리스 환경에서 진행합니다.

05   YOUR PROMPT, YOUR WAY

어떻게 요청할지도 직접 설계하세요.

기본 지시문으로 시작하고, 작업 방식에 맞게 프롬프트를 조정할 수 있습니다.

  • 작업별 기본 프롬프트와 응답 형식 예시를 제공해 구상·설명·로어북·코드 등 요청 목적을 구분합니다.
  • 시스템·사용자 템플릿을 확인·편집·저장하고, 필요하면 기본값으로 초기화합니다.
  • 요청 옆 프롬프트 창에서 실제로 보낼 메시지를 확인할 수 있습니다.
  • LLM 응답은 형식을 검증해 대화와 수정안으로 구분하고, JSON 바깥의 제목·코드 펜스·부가 설명을 정리합니다.

06   PRESETS & MODULES

익숙한 프리셋과 설치 모듈을 제작 자료로.

프롬프트 파일을 가져와 BB 안에서 편집하고, 사용할 모듈과 토글을 골라 요청에 연결하세요.

  • .risup·.risupreset·JSON 프리셋을 가져와 블록 순서·역할·본문과 v2 활성화 조건을 편집합니다.
  • 스위치·선택형·텍스트 토글을 설정하고, 사용자·페르소나·작가 노트·메모리 등 참고자료를 구성합니다.
  • 리스에 설치된 모듈을 검색·선택해 로어북 자료와 토글을 활용합니다. 요청에 포함된 블록과 모듈 자료도 확인할 수 있습니다.
  • 프리셋 설정 저장과 JSON 내보내기로 편집 결과를 보관합니다. 직접 요청 / 프리셋 요청을 선택해 작업합니다.
  • 가져온 사본을 BB 안에서 관리하며, 본체 프리셋·토글을 자동 동기화하지 않습니다. 지원하지 않는 CBS나 요청 관련 실행 처리는 확인 후 제외 여부를 정합니다.

07   SHOW, THEN TALK

이미지로 보여주고, 말로 구체화하세요.

원하는 분위기나 화면을 긴 설명만으로 전달하기 어려울 때, 참고 이미지를 요청에 함께 담아보세요.

  • PNG·JPG·WEBP 파일 첨부와 클립보드 붙여넣기를 지원합니다. 첨부한 이미지는 전송 전에 확인·삭제할 수 있습니다.
  • 이미지만 첨부해서 분석을 요청하거나, 설명을 덧붙여 제작 방향을 전달합니다. 이미지 입력을 지원하는 모델이 필요합니다.
  • 요청별 이미지를 대화 기록에 남기고, 필요한 때 이미지 다시 첨부로 재사용합니다. 이전 이미지는 다음 요청에 자동 재전송하지 않습니다.
  • 요청당 최대 4장, 장당 5MiB, 합계 12MiB까지 첨부합니다.

08   REVIEW BEFORE APPLY

AI의 제안과 내 원고 사이에, 검토할 시간을.

받은 답변을 읽고, 수정할 내용을 확인하고, 선택한 제안을 원고에 반영하는 흐름입니다.

  • 수정안과 원고를 분리해 보관합니다. 변경 내용을 확인한 뒤 직접 적용하고, 실제 캐릭터 저장은 별도로 진행합니다.
  • 요청 뒤 원고가 달라졌다면 오래된 제안을 그대로 적용하지 않습니다. 요청·응답 처리 중에는 진행 상태와 경과 시간을 확인하고 대기를 중단할 수 있습니다.
  • 본체 저장 시 최신 캐릭터에 변경 내용을 병합해 채팅 기록과 편집하지 않은 필드를 유지합니다.
  • 충돌이 생기면 처음 불러온 내용·리스의 현재 내용·BB 원고를 비교하고, 영역별로 저장할 쪽을 선택합니다. BB 원고를 고르면 해당 영역 전체가 교체되는 점도 안내합니다.

09   SAVE YOUR WORK

작업을 이어갈 수 있도록, 두 가지 저장 방식.

아이디어 대화와 편집 중인 원고를 함께 보관하고, 필요한 저장본에서 다시 시작하세요.

  • 3분 간격 자동 저장 최근 1개와 수동 임시 저장 최근 1개를 별도로 관리합니다.
  • 원고·제작 대화·수정안·프롬프트 편집 초안·요청 이미지와 작업 당시 프리셋 설정을 복원합니다.
  • 자동 저장과 임시 저장 중 원하는 저장본을 직접 선택해 불러옵니다. 복원한 내용의 본체 반영도 직접 결정합니다.

10   ASSETS → CHARX

봇 아이콘부터 배포할 캐릭터 파일까지.

캐릭터의 내용과 이미지를 한 작업 흐름에서 정리하고, 완성한 원고를 캐릭터나 파일로 저장하세요.

  • 봇 아이콘 등록·교체·해제로 대표 이미지를 관리합니다. 추가 이미지 에셋의 이름과 연결도 편집합니다.
  • 추가 에셋은 다중 선택·전체 선택·선택 삭제·전체 삭제로 정리합니다. 아이콘과 공유 파일을 별도로 구분해 다룹니다.
  • 리스의 캐릭터를 이름으로 검색하거나 현재 선택된 캐릭터를 불러오고, CHARX 가져오기로 파일 작업을 시작할 수 있습니다.
  • 기존 캐릭터에 저장·새 캐릭터로 저장·CCv3 CHARX 내보내기를 지원합니다. 대표 이미지와 확보한 내장 에셋을 포함하고, 유지한 외부 참조는 안내합니다.
  • CHARX 출력에는 플러그인의 에셋 합계 100MiB 제한을 두지 않습니다. 실제 처리 가능 크기는 브라우저 메모리와 이용 서비스에 따릅니다.

A WORKSPACE THAT FITS

책상에서는 넓게. 작은 화면에서는 간결하게.

  • PC에서는 원고와 제작 대화를 나란히 보며 작업합니다. 모바일에서는 원고·대화 전환과 접이식 요청 설정으로 공간을 활용합니다.
  • 라이트·무채색 다크·시스템 테마를 선택합니다. PC 버튼 도움말과 Ctrl + Enter 전송으로 반복 조작을 줄입니다.
  • 리스에 설정된 메인 모델 / 보조 모델을 선택해 요청합니다. 요청 대기 시간과 전체 전송 문자 한도도 조정할 수 있습니다.
  • 전체 전송 문자 한도는 기본 300만 자, 설정상 최대 1,000만 자입니다. 전체 전송은 32MiB 이내이며, 실제 입력 가능량은 사용하는 모델의 컨텍스트 한도를 따릅니다.
