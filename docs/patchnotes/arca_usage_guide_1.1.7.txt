<div style="padding:20px;margin-bottom:16px;border:1px solid #d6dad4;border-radius:12px;background:#ffffff;"><h2 style="margin:0 0 12px;color:#22302c;font-size:20px;line-height:1.5;">3. 토큰 아끼는 법</h2><ul style="margin:0 0 12px;padding-left:22px;"><li><strong>로어북은 필요한 항목만 체크:</strong> 로어북 탭의 <strong>이번 요청에 포함할 로어북</strong>에서 이번 작업과 관계없는 항목을 끕니다. 체크 상태는 어떤 요청 종류든 함께 적용되고, 원본 로어북의 "항상 활성화" 설정은 건드리지 않습니다. 로어북 100개짜리 봇에서 가장 효과가 큽니다.</li><li><strong>한 항목만 고칠 때는 범위를 잠그기:</strong> 로어북·정규식 요청에서 <strong>현재 선택한 항목만 수정</strong>을 켜면 그 항목 밖의 변경은 거부됩니다. <div style="padding:20px;margin-bottom:16px;border:1px solid #d6dad4;border-radius:12px;background:#ffffff;"><h2 style="margin:0 0 12px;color:#22302c;font-size:20px;line-height:1.5;">4. 수정안 검토와 적용</h2><ul style="margin:0 0 12px;padding-left:22px;"><li>응답이 오면 대화 아래에 <strong>원고 수정안</strong> 카드가 생깁니다. <strong>변경 내용 확인</strong>을 펼치면 구간·필드별로 전후 비교와 줄 번호가 보입니다. 설계 대화의 수정안은 여러 섹션이 한 카드에 들어 있습니다.</li><li>제목에 <strong>CBS 경고 N건</strong>이 붙으면 첫 메시지 등에 리스가 못 읽는 표기(<code>{{else}}</code> 같은 것)가 있다는 뜻입니다. 적용은 되지만 리스 화면에서 깨지므로 "{{else}}를 {{:else}}로 바꿔 줘"라고 다시 요청하세요.</li><li><strong>원고에 적용</strong>을 누르면 원고가 바뀌고, 바로 아래 <strong>적용 되돌리기</strong>가 나타납니다. 원고를 다시 편집하기 전까지 한 번 되돌릴 수 있습니다. 마음에 안 들면 <strong>폐기</strong>합니다.</li><li>원고를 손으로 고친 뒤에는 이전 수정안이 "원고가 변경됨"으로 잠깁니다. 현재 원고로 다시 요청하면 됩니다.</li><li>사이드바 탭 이름 옆의 점은 불러온 캐릭터(새 작업이면 빈 원고)와 달라진 탭입니다. 저장 전에 어디가 바뀌었는지 보는 용도입니다.</li></ul></div>

<div style="padding:20px;margin-bottom:16px;border:1px solid #d6dad4;border-radius:12px;background:#ffffff;"><h2 style="margin:0 0 12px;color:#22302c;font-size:20px;line-height:1.5;">5. 저장</h2><ul style="margin:0 0 12px;padding-left:22px;"><li><strong>캐릭터에 저장 / 새 캐릭터로 저장</strong>이 실제 봇에 반영하는 버튼입니다. 기존 캐릭터는 바뀐 영역만 병합하고 채팅 기록은 건드리지 않습니다. 리스에서 같은 영역을 동시에 고쳤으면 어느 쪽을 쓸지 묻는 비교 창이 뜹니다.</li><li><strong>charx 내보내기</strong>는 파일로 저장합니다. 에셋 탭에서 봇 아이콘과 추가 에셋을 정리할 수 있습니다.</li><li>작업 중에는 3분마다 <strong>자동 저장</strong>(최근 3개)되고, <strong>임시 저장</strong>으로 수동 저장본 1개를 따로 둘 수 있습니다. 다시 열 때 복원 창이 뜨며, 원고·대화·미적용 수정안이 함께 돌아옵니다. 저장본을 불러와도 설정값은 바뀌지 않습니다.</li></ul></div>
