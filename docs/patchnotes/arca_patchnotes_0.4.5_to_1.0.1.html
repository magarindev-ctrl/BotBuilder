이번 업데이트 핵심

봇빌더(BB)는 LLM과 대화하며 캐릭터·시뮬레이션을 만드는 RisuAI / RisuBard API v3 플러그인입니다. 이번에도 본체 수정 없이 단일 JS 플러그인 안에서 동작합니다.

고침탭만 눌러도 '원고 편집 중'이 되고 빈 원고가 자동 저장돼 다음에 열 때 복원 창이 뜨던 문제
추가수정안 적용 되돌리기, 자동 저장 최근 3개, 닫을 때까지 남는 오류 안내
화면지금 어떤 작업(설계 대화·캐릭터 설명·로어북…)을 요청 중인지 입력창·메시지·모바일 버튼에 표시, 바뀐 탭에 점 표시, 글자 대비 개선
모바일제목 아래 저장 상태, 탭 바 넘침 표시, 수정안 변경 내용 기본 펼침, 회전 시 다시 그리기

v1.0.1 · 동작 수정

열기만 해도 생기던 빈 자동 저장본

봇빌더를 열고 사이드바 탭 하나만 눌러도 상태가 '원고 편집 중'으로 바뀌고, 3분 뒤 빈 원고가 자동 저장됐습니다. 그래서 다음에 열면 "이어서 작업할 저장본이 있습니다" 창이 떴는데 내용은 비어 있었습니다.

  • 탭 이동, 항목 선택, 모델 선택은 더 이상 작업을 시작하지 않습니다. 원고·제작 노트·대화·요청문을 실제로 입력했을 때만 시작합니다.
  • 모델만 바꾸고 캐릭터를 불러올 때 "지금 작업을 바꿀까요?"가 뜨던 것도 같은 원인이라 함께 사라졌습니다.

수정안 적용 되돌리기

  • 수정안을 원고에 적용한 직후 대화 아래에 적용 되돌리기가 나타납니다. 누르면 적용 전 원고로 돌아가고 수정안은 다시 검토 대기 상태가 됩니다.
  • 원고를 다시 편집하면 되돌리기는 사라집니다. 한 단계만 되돌리며, 그 이전은 저장본 복원을 사용하세요.

자동 저장 3개 · 오류 안내

  • 자동 저장을 최근 3개(최근 · 1회 전 · 2회 전)로 늘렸습니다. 저장본 불러오기에서 모두 고를 수 있고, 수동 임시 저장 1개는 그대로입니다.
  • 오류 안내가 7초 뒤 사라지지 않고 닫기를 누를 때까지 남습니다. 본문을 길게 눌러 복사할 수 있고, 모바일에서는 입력창을 가리지 않도록 상단에 뜹니다.

v1.0.1 · 화면

지금 무엇을 요청하는지 바로 보이게

  • 입력창 바로 위에 작업 표시줄이 생겼습니다. '캐릭터 설명', '로어북' 같은 현재 작업 이름과 그 작업이 바꾸는 범위가 한 줄로 붙습니다. 설계 대화는 회색, 개별 작업은 녹색이라 통합 변경인지 개별 작업인지 색으로 구분됩니다.
  • 설계 대화가 아닌 요청과 답변에는 '나 · 캐릭터 설명'처럼 작업 태그가 붙어 나중에 봐도 어떤 작업의 대화였는지 알 수 있습니다.
  • 사이드바에서 불러온 캐릭터(새 작업이면 빈 원고)와 다른 탭 옆에 점이 표시됩니다. 저장 전에 어디가 바뀌었는지 한눈에 보입니다.
  • 대화 라벨을 '나 / 작성 파트너'로, 상단 상태 문구를 '자동 저장 · 임시 저장'으로 바꿨습니다.
  • 라이트 테마의 회색 보조 글자와 작은 라벨을 WCAG AA 기준(4.5:1) 이상으로 진하게 했습니다. 다크 모드는 무채색을 유지하면서 수정안 카드 왼쪽 가장자리와 주 버튼 굵기로 구분합니다.

v1.0.1 · 모바일

휴대폰 화면 보완

  • 제목 아래 한 줄에 '편집 중 · 자동 05:46 · 임시 없음'처럼 편집 상태와 저장 시각이 보입니다.
  • 상단 탭 바에 가려진 탭이 있으면 오른쪽 끝이 흐려집니다. 끝까지 넘기면 흐림이 사라집니다.
  • 요청 설정 버튼에 현재 작업 이름이 표시되고('캐릭터 설명 ▾'), '대화 비우기' 왼쪽에 그 작업이 바꾸는 범위 설명이 붙습니다.
  • 수정안 카드의 변경 내용이 기본으로 펼쳐져 전후 비교가 바로 보입니다. PC에서는 그대로 접혀 있습니다.
  • 화면을 회전하거나 분할 화면으로 폭이 바뀌면 화면을 다시 그립니다. 요청 처리 중에는 그리지 않습니다.

v0.4.6 ~ v1.0.0 · 이전 패치노트 이후

정식 1.0.0까지의 변경

  • v0.4.6: 캐릭터 불러오기와 대체 인사말 목록이 [object HTMLButtonElement]로 표시되던 오류를 고쳤습니다.
  • v0.4.8: 요청에 PNG·JPG·WEBP 이미지를 첨부하거나 붙여넣을 수 있습니다. 요청당 4장, 장당 5MiB, 합계 12MiB. 이미지 입력을 지원하는 모델이 필요합니다.
  • v0.4.9: 모바일 상단에 원고·대화 전환과 작업 메뉴를 두고 요청 설정을 접었습니다. 키보드 표시에 맞춰 대화 영역을 조정합니다.
  • v0.4.15: 모바일 수정 빌드를 소스로 역동기화했습니다. 저장 충돌 시 처음 불러온 내용·리스의 현재 내용·BB 원고를 비교해 영역별로 고릅니다. CHARX는 확보하지 못한 에셋 참조의 URI와 안내를 남깁니다.
  • v0.4.16: PC의 이미지 첨부·요청 안내문을 버튼 도움말로 옮겼습니다.
  • v1.0.0: 패키지·런타임·배포 헤더 버전을 통일하고, 플러그인 헤더에 GitHub 업데이트 주소를 넣어 리스의 플러그인 업데이트 버튼으로 교체할 수 있게 했습니다.

설치 · 업데이트

  • 1.0.0을 쓰고 있다면: RisuBard 설정 → 플러그인에서 봇빌더의 업데이트 버튼을 누르면 1.0.1로 교체됩니다. 저장한 프롬프트·프리셋·저장본은 유지됩니다.
  • 처음 설치하거나 업데이트 주소가 없는 옛 설치본이라면: 아래 설치 파일 risu_story_workshop.js를 받아 기존 플러그인을 지우고 다시 추가합니다.
  • 설치 후 플러그인 설정 항목 또는 햄버거 메뉴의 봇빌더를 엽니다. 모델과 접속 정보는 리스의 메인·보조 모델 설정을 따릅니다.
실제 RisuBard의 LLM 호출·Lua 실행·강제 종료 후 복구는 모의 환경에서만 확인했습니다. 자동 검증 150개와 브라우저 검증 26개를 통과했지만, 설치 후 실제 환경에서 한 번 확인해 주세요.
