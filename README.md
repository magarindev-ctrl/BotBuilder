# 이야기 공방

LLM과 대화하며 RisuBard용 캐릭터·시뮬레이션을 만들어 가는 API v3 플러그인입니다. PC에서는 원고와 제작 대화를 나란히 봅니다.

## 설치와 시작

1. RisuBard의 설정 → 플러그인에서 **`dist/risu_story_workshop.js`**를 추가합니다. 이 파일 하나에 모든 실행 코드가 들어 있습니다.
2. 플러그인 설정 항목 또는 햄버거 메뉴의 **이야기 공방**을 엽니다.
3. 새 작업을 시작하거나 기존 캐릭터·charx를 불러옵니다.
4. 제작 노트에 방향을 적고, 오른쪽 **설계 대화 → 함께 구상하기**로 LLM과 의논합니다. 모델과 접속 정보는 RisuBard의 메인·보조 모델 설정을 따릅니다.
5. 설명·로어북·정규식·Lua·첫 메시지 요청으로 구체화합니다. **변경 내용 확인 → 원고에 적용**으로 수정안을 채택합니다.
6. **캐릭터에 저장 / 새 캐릭터로 저장** 또는 **charx 내보내기**로 결과를 저장합니다.

## 포함한 기능

- 설정에서 시스템 설정 따르기 / 라이트 모드 / 무채색 다크 모드를 선택하고 저장합니다. 본문은 자체 배경으로 플러그인 프레임을 채우며, 창 크기에 맞춰 원고와 대화 영역의 스크롤을 분리합니다.
- 설계 대화, 제작 노트, 기존 원고를 참고하는 작업별 생성·수정 요청.
- 설명·성격·시나리오, 로어북, 정규식과 HTML/CSS 원문, Lua·초기 변수, 첫 메시지·대체 인사말, 이미지 에셋 목록 편집.
- 요청 버튼 옆의 **프롬프트**에서 전체 시스템·사용자 템플릿 확인, 편집·저장·기본값 초기화. 미저장 편집 내용은 전송에 사용하지 않습니다.
- 요청 버튼을 누르면 별도 확인창 없이 전송합니다. 실제 전송 메시지는 프롬프트 창에서 선택적으로 확인할 수 있습니다. 작업 중 애니메이션·경과 시간, 대기 중단과 시간 초과를 지원하며 플러그인 자체의 자동 재시도는 없습니다.
- 내장 기본 프롬프트는 허구의 세계관, 인물의 동기·행동 일관성, 사건 결과, 개인정보와 참고자료·예시 해석을 안내합니다. 기존에 저장한 사용자 프롬프트는 유지하고, `기본값으로 초기화`하면 새 기본 문안을 불러옵니다.
- 미적용 제안과 원고의 분리. 원고가 변경되면 이전 제안을 적용하지 않습니다.
- 3분 자동 저장 최근 1개 + 수동 임시 저장 최근 1개. 대화·원고·완료된 제안·프롬프트 편집 초안을 함께 복원합니다.
- 최신 캐릭터에 변경 내용을 병합하고 대화·편집하지 않은 필드를 유지합니다. 충돌은 저장을 중단하고 표시합니다.
- 정규식 매칭·캡처·치환 결과의 텍스트 검사. 생성한 HTML/CSS를 렌더링하거나 Lua를 실행하지 않습니다.
- CCv3 charx 읽기·쓰기, RisuAI 모듈의 로어북·정규식·트리거와 내장 이미지 에셋 처리.

## 현재 검증 범위

버전은 **0.1.2**입니다. 자동 검증과 실제 브라우저에서 모의 API를 연결한 UI 검증을 수행했습니다. UI 검증에는 리스바드처럼 숨겨진 `srcdoc` iframe과 투명 body에서 시작해 화면을 여는 조건, 여러 창 크기와 재열기가 포함됩니다. 기준 소스는 RisuAI `f50b5942…`, RisuBard `e5412a48…`이며, 사용자의 실제 설치 버전과 동일하다고 가정하지 않습니다.

**실제 RisuBard의 LLM 호출, Lua·상황 선택 단추 실행, 강제 종료 후 복구는 아직 확인하지 못했습니다.** 저장 API 완료와 디스크·동기화 반영 시점은 다를 수 있습니다. 설치 후 실제 환경에서 확인해야 합니다.

정규식 테스트는 RE2JS 공통 문법을 사용합니다. 역참조·전방 탐색, 지원하지 않는 플래그는 테스트를 거부하고 원고 편집은 유지합니다. CBS·실제 채팅 상태를 실행하지 않으므로 `{{data}}` 등 매크로는 문자 그대로 표시될 수 있습니다. 패턴 1,024자 / 입력 65,536자 / 매칭 1,000개 / 출력 1MiB 한도를 표시합니다.

charx 입력은 100MiB, 압축 해제는 200MiB 이하입니다. 별도 모듈 에셋, 외부 URL 에셋, 해석할 수 없는 참조는 오류를 표시합니다. 이 경우 RisuBard 본체로 먼저 가져온 뒤 공방에서 캐릭터를 불러오세요. 카드 가져오기로 저수준 실행 권한을 자동 허용하지 않습니다.

## 개발

```powershell
npm ci
npm run build
npm test
node tools/verify-browser.mjs
```

브라우저 검증은 Windows의 설치된 Edge를 기본으로 사용합니다. 다른 실행 파일은 `WORKSHOP_BROWSER` 환경 변수로 지정할 수 있습니다. 결과와 소스 검증은 `verification/`, 화면 캡처는 `artifacts/`에 있습니다.

유지보수용 소스는 `src/`에 나뉘어 있고 배포 시 하나의 JS로 합쳐집니다. DUSK는 편집 편의성을 검토하는 참고 자료로 사용했으며 소스와 화면을 복제하지 않았습니다. 포함한 외부 라이브러리의 고지는 `THIRD_PARTY_NOTICES.txt`와 배포 JS에 있습니다.
