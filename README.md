# 이야기 공방

LLM과 대화하며 RisuBard용 캐릭터·시뮬레이션을 만들어 가는 API v3 플러그인입니다. PC에서는 원고와 제작 대화를 나란히 봅니다.

## 설치와 시작

1. RisuBard의 설정 → 플러그인에서 **`dist/risu_story_workshop.js`**를 추가합니다. 이 파일 하나에 모든 실행 코드가 들어 있습니다.
2. 플러그인 설정 항목 또는 햄버거 메뉴의 **이야기 공방**을 엽니다.
3. 새 작업을 시작하거나 기존 캐릭터·charx를 불러옵니다.
4. 제작 노트에 방향을 적고, 오른쪽 **설계 대화 → 함께 구상하기**로 LLM과 의논합니다. 모델과 접속 정보는 RisuBard의 메인·보조 모델 설정을 따릅니다.
5. 설명·로어북·정규식·Lua·첫 메시지 요청으로 구체화합니다. **변경 내용 확인 → 원고에 적용**으로 수정안을 채택합니다.
6. **캐릭터에 저장 / 새 캐릭터로 저장** 또는 **charx 내보내기**로 결과를 저장합니다.

## 포함한 기능

- 설정에서 시스템 설정 따르기 / 라이트 모드 / 무채색 다크 모드를 선택하고 저장합니다. 본문은 자체 배경으로 플러그인 프레임을 채우며, 창 크기에 맞춰 원고와 대화 영역의 스크롤을 분리합니다.
- 설계 대화, 제작 노트, 기존 원고를 참고하는 작업별 생성·수정 요청.
- 설명·성격·시나리오, 로어북, 정규식과 HTML/CSS 원문, Lua·초기 변수, 첫 메시지·대체 인사말, 이미지 에셋 목록 편집.
- 요청 버튼 옆의 **프롬프트**에서 전체 시스템·사용자 템플릿 확인, 편집·저장·기본값 초기화. 미저장 편집 내용은 전송에 사용하지 않습니다.
- 요청 버튼을 누르면 별도 확인창 없이 전송합니다. 실제 전송 메시지는 프롬프트 창에서 선택적으로 확인할 수 있습니다. 작업 중 애니메이션·경과 시간, 대기 중단과 시간 초과를 지원하며 플러그인 자체의 자동 재시도는 없습니다.
- 내장 기본 프롬프트는 허구의 세계관, 인물의 동기·행동 일관성, 사건 결과, 개인정보와 참고자료·예시 해석을 안내합니다. 기존에 저장한 사용자 프롬프트는 유지하고, `기본값으로 초기화`하면 새 기본 문안을 불러옵니다.
- 미적용 제안과 원고의 분리. 원고가 변경되면 이전 제안을 적용하지 않습니다.
- 3분 자동 저장 최근 1개 + 수동 임시 저장 최근 1개. 대화·원고·완료된 제안·프롬프트 편집 초안을 함께 복원합니다.
- 최신 캐릭터에 변경 내용을 병합하고 대화·편집하지 않은 필드를 유지합니다. 충돌은 저장을 중단하고 표시합니다.
- 정규식 매칭·캡처·치환 결과의 텍스트 검사. 생성한 HTML/CSS를 렌더링하거나 Lua를 실행하지 않습니다.
- CCv3 charx 읽기·쓰기, RisuAI 모듈의 로어북·정규식·트리거와 내장 이미지 에셋 처리.
- `.risup`·`.risupreset`·JSON 프롬프트 프리셋 가져오기, 블록 순서·역할·본문·v2 활성화 조건 편집, 토글 설정과 조립된 전송 내용 확인.

## 가져온 프롬프트 프리셋 사용

1. 본체에서 프리셋을 파일로 내보낸 뒤 공방의 **프롬프트 프리셋 → 프리셋 가져오기**에서 선택합니다. 가져오면 요청 구성이 **프리셋 요청**으로 바뀝니다.
2. **프롬프트 블록**에서 본문·역할·순서·사용 여부와 v2 조건을 편집합니다. 제작 대화 블록에는 현재 공방 요청이 정확히 한 번 포함되도록 범위를 설정합니다. `0 → end`는 전체 제작 대화와 이번 요청입니다.
3. **토글 설정**에서 스위치·선택형·텍스트·여러 줄 값을 정합니다. 선택형 토글의 CBS 값은 본체처럼 0부터 시작하는 번호입니다. **참고자료**에서 사용자 이름·페르소나·작가 노트·메모리와 추가 전역 변수를 입력할 수 있습니다.
4. **전송 내용**에서 포함·제외된 블록, 오류와 역할별 전체 메시지를 확인하고 기존 요청 버튼으로 전송합니다. 작업 지침·현재안·출력 형식을 포함한 공방 요청을 제작 대화 블록의 사용자 메시지 자리에 넣고, 이전 제작 대화는 채팅 블록의 범위를 따릅니다. 요청 옆 **프롬프트**에서도 실제 조립 결과를 볼 수 있습니다.
5. **프리셋 설정 저장**으로 편집본·토글 선택·요청 구성을 플러그인 저장소에 보관합니다. 자동 저장·수동 임시 저장에도 작업 당시 프리셋을 포함합니다. **JSON 내보내기**는 비활성 블록을 제외한 프롬프트 사본이며, 공방 토글 선택값·참고자료는 포함하지 않습니다. 원문·고급 JSON 편집은 해당 **적용** 버튼을 눌러야 반영됩니다.

본체 코드는 변경하지 않으며, 빈 캐릭터나 본체 채팅을 통한 요청 가로채기는 사용하지 않습니다. 가져온 사본과 토글 값은 공방 안에서 관리합니다. 본체의 현재 프리셋·토글과 자동 동기화하지 않고, 파일의 모델·API 키·접속 설정도 가져오지 않습니다. 실행 모델은 기존 **메인 모델 / 보조 모델** 선택을 따릅니다. **직접 요청**으로 바꾸면 기존 동작을 사용합니다.

지원 범위는 다음과 같습니다. 본체의 전체 프롬프트 엔진과 동일한 결과를 보장하는 이식은 아닙니다.

| 항목 | 공방 처리 |
| --- | --- |
| 파일 | `.risup`의 RPack·압축·MessagePack·AES-GCM, `.risupreset`, UTF-8 JSON. 입력·압축 해제 각각 8MiB 이하, 블록 500개 이하 |
| 블록 | 일반·구형 추가 프롬프트·CoT, ChatML, 대화 범위, 설명·페르소나·작가 노트·로어북·메모리 입력·마지막 지시, assistant prefill. 구형 활성화 플래그가 있으면 유지 |
| v2 | 조건 추가·삭제, AND/OR, 같음·다름·대소 비교, 토글 그룹·설명·구분선 |
| CBS | `char`, `user`, `description`, `personality`, `scenario`, `persona`, `firstmessage`/`first_message`, `systemprompt`, `lorebook`, `chatindex`, `lastusermessage`, `lastcharmessage`, `original`, `slot`; `getglobalvar`, `getvar`, 비교·논리 함수, `#if`/`#if_pure`/`#when`, else, 주석, trim·lower·upper |
| 자료 연결 | 설명·로어북은 공방 현재안, 대화는 공방 제작 대화. 로어북은 전체 항목을 넣고 본체의 키워드 활성화·검색·토큰 예산은 실행하지 않음. 페르소나·작가 노트·메모리는 공방 입력값 |
| 별도 처리 | 외부 모듈·프리셋 정규식·보조 오버레이는 기본적으로 전송을 막고, 참고자료 탭에서 사용자가 명시적으로 제외 가능. 캐시 블록·지원하지 않는 CBS는 수정하거나 블록 사용을 꺼야 함 |

CBS는 지원 목록만 해석하며 코드 실행·본체 변수 변경은 제공하지 않습니다. 원고·사용자 요청·토글 입력값을 다시 CBS로 해석하지 않습니다. 감싸는 서식은 `{{slot}}`을 포함해야 합니다. 로어북·메모리·마지막 지시의 감싸는 서식도 공방 자료에 적용하는 자체 어댑터입니다. 본체의 첫 인사·예시 대화·새 채팅 표시는 제작 대화에 자동 삽입하지 않으며, `trimStartNewChat`·`maxThoughtTagDepth` 같은 해당 본체 전용 처리는 적용하지 않습니다. `sendChatAsSystem`·`sendName`·`utilOverride`·`customChainOfThought`가 활성화된 파일은 미지원 옵션을 표시하고 전송을 중단합니다. 입력은 기존 문자 수 한도를 그대로 적용하며 자동 토큰 절삭을 하지 않습니다.

## 현재 검증 범위

버전은 **0.2.0**입니다. 자동 검증 47개와 실제 Edge에서 모의 API를 연결한 UI 검증 12개를 수행했습니다. 숨겨진 `srcdoc` iframe·투명 body·CSP, 18개 본문 배치 조건, 재열기와 프롬프트 창, 바이너리 프리셋 가져오기·토글·편집·실제 전달 메시지를 확인했습니다. 프리셋 파일은 확인한 공식 내보내기 형식대로 별도 생성한 검증용 파일이며 사용자 파일 검증은 아닙니다. 기준 소스는 RisuAI `f50b5942…`, RisuBard `e5412a48…`이며, 사용자의 실제 설치 버전과 동일하다고 가정하지 않습니다.

**실제 RisuBard의 LLM 호출, Lua·상황 선택 단추 실행, 강제 종료 후 복구는 아직 확인하지 못했습니다.** 저장 API 완료와 디스크·동기화 반영 시점은 다를 수 있습니다. 설치 후 실제 환경에서 확인해야 합니다.

정규식 테스트는 RE2JS 공통 문법을 사용합니다. 역참조·전방 탐색, 지원하지 않는 플래그는 테스트를 거부하고 원고 편집은 유지합니다. CBS·실제 채팅 상태를 실행하지 않으므로 `{{data}}` 등 매크로는 문자 그대로 표시될 수 있습니다. 패턴 1,024자 / 입력 65,536자 / 매칭 1,000개 / 출력 1MiB 한도를 표시합니다.

charx 입력은 100MiB, 압축 해제는 200MiB 이하입니다. 별도 모듈 에셋, 외부 URL 에셋, 해석할 수 없는 참조는 오류를 표시합니다. 이 경우 RisuBard 본체로 먼저 가져온 뒤 공방에서 캐릭터를 불러오세요. 카드 가져오기로 저수준 실행 권한을 자동 허용하지 않습니다.

## 개발

```powershell
npm ci
npm run build
npm test
node tools/verify-browser.mjs
```

브라우저 검증은 Windows의 설치된 Edge를 기본으로 사용합니다. 다른 실행 파일은 `WORKSHOP_BROWSER` 환경 변수로 지정할 수 있습니다. 결과와 소스 검증은 `verification/`, 화면 캡처는 `artifacts/`에 있습니다.

유지보수용 소스는 `src/`에 나뉘어 있고 배포 시 하나의 JS로 합쳐집니다. DUSK는 편집 편의성을 검토하는 참고 자료로 사용했으며 소스와 화면을 복제하지 않았습니다. 포함한 외부 라이브러리의 고지는 `THIRD_PARTY_NOTICES.txt`와 배포 JS에 있습니다.

프리셋 어댑터는 RisuBard의 [파일 입출력](https://github.com/rpaddict/RisuBard/blob/e5412a4878ae3a0073ffce8e06aed8f288dd9c53/src/ts/storage/database.svelte.ts), [v2 조건·토글](https://github.com/rpaddict/RisuBard/blob/e5412a4878ae3a0073ffce8e06aed8f288dd9c53/src/ts/promptV2.ts), [프롬프트 조립](https://github.com/rpaddict/RisuBard/blob/e5412a4878ae3a0073ffce8e06aed8f288dd9c53/src/ts/process/index.svelte.ts)을 대조했습니다. 순수 조건·토글 함수를 수정해 사용하고 UI는 본체 저장소에 의존하지 않도록 작성했습니다. 해당 코드의 GPL 조건에 따라 프로젝트와 배포물은 **GPL-3.0-only**로 제공하며 전문은 `LICENSE`와 배포 JS에 포함합니다. 배포 JS를 재배포할 때 대응 소스·빌드 파일과 라이선스도 함께 제공하세요.
