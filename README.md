# 봇빌더 (BB)

LLM과 대화하며 RisuBard용 캐릭터·시뮬레이션을 만들어 가는 RisuAI API v3 플러그인입니다. 원고와 제작 대화를 나란히 두고, LLM의 제안을 검토한 뒤에만 원고에 적용합니다. 본체 코드는 바꾸지 않으며 모델·접속 정보는 리스의 메인·보조 모델 설정을 그대로 씁니다.

## 설치

1. [최신 배포 JS](https://raw.githubusercontent.com/magarindev-ctrl/BotBuilder/main/dist/risu_story_workshop.js)를 내려받거나 저장소의 `dist/risu_story_workshop.js`를 사용합니다. 이 파일 하나에 모든 실행 코드와 라이선스 고지가 들어 있습니다.
2. RisuBard의 **설정 → 플러그인**에서 파일을 추가합니다.
3. 플러그인 설정 항목 또는 햄버거 메뉴의 **봇빌더**를 엽니다.

## 5분 흐름

1. **＋ 새 작업**을 누르거나 **캐릭터 불러오기 / charx 열기**로 기존 원고를 가져옵니다.
2. **제작 노트**에 장르·사용자 역할·분위기·규칙을 적습니다. 이 노트는 모든 요청에 참고자료로 들어갑니다.
3. 오른쪽 **설계 대화**에서 **함께 구상하기**로 방향을 의논합니다. 대화만 할 때는 원고가 바뀌지 않습니다.
4. 설명·로어북·정규식·Lua·첫 메시지 탭에서 **LLM과 … 다듬기**를 눌러 작업별 수정안을 요청합니다. 요청 옆 **프롬프트**에서 실제 전송 내용을 볼 수 있습니다.
5. 대화 아래의 **원고 수정안**에서 **변경 내용 확인 → 원고에 적용**으로 채택합니다. 잘못 적용했으면 바로 **적용 되돌리기**를 누릅니다.
6. **캐릭터에 저장 / 새 캐릭터로 저장** 또는 **charx 내보내기**로 결과를 저장합니다. 작업 중에는 3분마다 자동 저장되고(최근 3개), **임시 저장**으로 수동 저장본 1개를 따로 둘 수 있습니다.

## 플러그인 업데이트

- 배포 JS 헤더에 업데이트 주소가 들어 있어, 새 버전이 나오면 리스의 플러그인 업데이트 버튼으로 교체할 수 있습니다. 자동 설치는 아닙니다.
- 업데이트 주소가 없는 이전 설치본은 위 파일을 한 번 직접 가져와 기존 플러그인을 교체해야 합니다.
- 변경 내용은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

## 주요 기능

- 설계 대화, 제작 노트, 기존 원고를 참고하는 작업별 생성·수정 요청. 응답은 검증된 JSON만 처리하고 사용자가 검토한 뒤 적용합니다.
- 설명·성격·시나리오, 로어북, 정규식과 HTML/CSS 원문, Lua·초기 변수, 첫 메시지·대체 인사말·상황 선택 단추, 이미지 에셋과 봇 아이콘 편집.
- 기존 원문의 구간만 바꾸는 부분편집과 줄 번호 검토, 원문이 애매할 때의 후보 선택.
- 긴 결과는 모델이 구간 계획을 세우고 봇빌더가 임시 원고 위에서 자동으로 이어 요청하는 분할 작업. 끊긴 응답은 더 작은 구간으로 한 번 자동 재시도하고, 검토와 적용은 구간 묶음 하나로 한 번만 합니다.
- 요청에 이미지 첨부(최대 4장), 로어북 항목별 포함 선택, 시스템·사용자 프롬프트 편집.
- `.risup`·`.risupreset`·JSON 프롬프트 프리셋 가져오기와 블록·토글 편집, 리스에 설치된 모듈의 로어북·토글 연동.
- CCv3 charx 읽기·쓰기, 최신 캐릭터와의 병합 저장과 충돌 비교, 정규식 텍스트 테스트.
- 시스템 설정 따르기 / 라이트 / 무채색 다크 테마, PC 2단 화면과 모바일 화면.
- Dusk Atelier 연동(DA Interop v1). Dusk에서 봇빌더를 바로 열고 작업 중인 원고를 읽어 갈 수 있습니다. 봇빌더 쪽은 읽기 전용이며 Dusk가 없으면 아무 변화가 없습니다.

## 알아두기

- 전체 전송 문자 한도는 기본 3,000,000자(설정 1,000~10,000,000자), 전송 내용 32MiB, 응답 1MiB, LLM 대기 기본 900초입니다. 글자 수는 토큰 수가 아니므로 모델·API의 컨텍스트 여유가 필요합니다.
- 생성한 HTML/CSS를 렌더링하거나 Lua를 실행하지 않습니다. 정규식 테스트는 RE2JS 문법의 텍스트 검사입니다.
- 프리셋 요청은 본체의 프롬프트 엔진을 그대로 옮긴 것이 아닙니다. 지원하는 블록·CBS·모듈 기능과 전송을 막는 항목은 [docs/presets.md](docs/presets.md)에 있습니다.
- 실제 RisuBard의 LLM 호출, Lua·상황 선택 단추 실행, 강제 종료 후 복구는 모의 환경에서만 확인했습니다. 설치 후 실제 환경에서 확인해야 합니다. 자세한 범위는 [docs/verification.md](docs/verification.md)를 보세요.

## 개발

```
npm ci
npm test
npm run build
node tools/verify-browser.mjs
```

소스는 `src/`에 있고 `npm run build`가 `dist/risu_story_workshop.js` 하나로 묶습니다. 빌드는 `package.json`과 런타임 버전이 다르면 중단합니다. GitHub Actions가 테스트·빌드·dist 일치 검사를 돌립니다. 작업 지침은 [agent.md](agent.md)에 있습니다.
